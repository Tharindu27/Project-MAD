# MAD - Smart Home Monitoring & Control System

This workspace contains the Smart Home Monitoring & Control System demo project.

## 🚀 How to Run the Project Locally

Follow these steps to set up and run the Flutter application on your local machine:

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
- Android Studio / VS Code with Flutter extension
- An active Android Emulator or Physical Android Device (with USB Debugging enabled)

### Step-by-Step Setup

#### 1. **Clone the Repository**
  -  git clone [https://github.com/Tharindu27/Project-MAD.git](https://github.com/Tharindu27/Project-MAD.git)
   
#### 2.Navigate to the Flutter App Directory
 -  cd Project-MAD/smarthome

#### 3.Install Dependencies
  - flutter pub get

#### 4.Firebase Setup (Important)
  - Make sure to place the valid google-services.json file inside the smarthome/android/app/ directory if it is missing.

#### 5.Run the Application
 -  flutter run


#### 📱 Download Compiled APK
- You can directly download and install the release APK:

- Download app-release.apk
